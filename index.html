ASSIGNMENT PRESENTATION & CODE GUIDE

Core Architecture & Concepts Explained

This application was constructed using clean Vanilla JavaScript, standard HTML5 semantics, and CSS Glassmorphism to fulfill all academic project requirements.

1. Asynchronous TMDB API Integration (`fetch` & `async/await`)

The app connects to TMDB's RESTful search endpoint using native JavaScript `fetch()` wrapped inside an `async/await` try-catch block for clean asynchronous network calls.

async function searchMoviesFromTMDB(query) { const url = `https://api.themoviedb.org/3/search/movie?api_key=${API_KEY}&query=${encodeURIComponent(query)}`; const response = await fetch(url); const data = await response.json(); return data.results; // Array of movie objects }

2. LocalStorage Persistence & Data Syncing

Whenever a movie is created, updated, or deleted, `localStorage.setItem('cyber_watchlist', JSON.stringify(watchlist))` serializes the JavaScript array into JSON for persistent browser storage across refreshes.

function saveWatchlistToStorage() { localStorage.setItem('cyber_watchlist', JSON.stringify(state.watchlist)); } function loadWatchlistFromStorage() { const saved = localStorage.getItem('cyber_watchlist'); return saved ? JSON.parse(saved) : INITIAL_WATCHLIST_SAMPLES; }

3. Full CRUD Lifecycle

• C (Create): `addMovieToWatchlist(movieData)` adds a movie with status, rating, and review notes.
• R (Read): `renderWatchlistGrid()` dynamically maps the watchlist array to HTML cards.
• U (Update): `updateWatchlistMovie(id, updates)` modifies watch status, star rating, or notes.
• D (Delete): `deleteWatchlistMovie(id)` removes a movie after confirmation.

Assignment Submission Tips

  • Live TMDB API vs Demo Mode: Explain that your application features an intelligent dual-mode fallback engine. If an API key is present, it queries real-time TMDB servers; otherwise, it operates smoothly using local Cyber Deck mock data.
  • No External Frameworks Needed: Highlight that the entire app runs purely on native browser APIs without heavy dependencies like React or jQuery, keeping performance lightweight and blazingly fast.
